机器人闭环适应 · 回顾

CLIFT: Turning Gemini Robotics On-Device into Humanoid Specialists via Non-Invasive Closed-Loop Iterative Fine-Tuning

2026-07-31

UC Berkeley / Google DeepMind / NVIDIA Research · CoRL 2026 主会论文 · 实机

方法与结果　研究只能调用监督微调 API、无法访问权重与梯度时，如何利用机器人自身执行反馈改进策略。CLIFT 用人类偏好校准的稠密奖励给动作片段打分，将优势标签写入监督数据并反复微调；在 Unitree G1 三项任务中，两轮后装箱、插杯和双手递盘的成功率分别从 93%、70%、53% 提升至 100%、98%、96%，每项测试 100 次。

证据范围　证据来自三个任务及同一实机控制栈；依赖初始演示、人类偏好和已有基础模型。该结果说明任务内闭环适应有效，未证明改进后的学习机制能在重置学习器、未见任务和匹配预算下继续带来增益，因此不能据此宣称严格的机器人 RSI。

AI agents · 验证与可靠性

Introducing AlphaProof Code: a breakthrough in verifying complex software at depth

2026-11-10

Google DeepMind · 官方研究博客 / 技术论文

方法与结果　将专家审核的形式化规格、多个证明 agent 与 Lean 检查器组合起来，验证 Signal 核心密码协议实现满足指定安全性质。官方报告称四周内生成逾 600 万行 Lean 证明，并在重新注入两个历史真实漏洞后，都生成了漏洞版本不安全的机器可检查证明；值得关注的是把生成端与可信验证端分开的工程路线。

证据范围　这是特定协议和指定安全性质的验证案例；规格仍须专家审查，结论受形式模型、假设与验证边界约束。不能外推为整个应用没有漏洞；四周与历史多年工程的比较也不是严格匹配人力、算力的对照实验。

模型自训练 · Agent 监控

What affects chain-of-thought monitorability across the model lifecycle?

2026-11-10

OpenAI · 官方研究博客

方法与结果　分析预训练、架构、强化学习及模型生成数据如何影响无思维链推理能力与思维链可控性。在仅约束长度并按最终答案评分的 RL 中，可控性仍会上升；教师能力相近、提示分布和 token 预算固定的蒸馏实验还发现，更可控教师生成的数据会得到更可控的学生。对自改进流水线的启示是，不能只追踪任务得分，也应检查监督信号是否仍可观测。

证据范围　两项指标是监控难度的代理，并非直接的恶意行为或监控逃逸概率；作者明确记录了代理与直接监控指标不一致的情况。部分实验来自内部模型与评测，工具监督实验也未完全隔离困惑度等因素，不能给出普适的部署风险数值。
