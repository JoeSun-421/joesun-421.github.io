Catch Me If You Can: Real-Time Feedback Denoising for Responsive VLAs

2026-09-17

得克萨斯大学奥斯汀分校 / 中佛罗里达大学 · CoRL 2026 主会论文 · 仿真与实机

方法与结果　VLA-Feedback 将慢速扩散规划器的最后一步去噪留给轻量反馈模块，在动作块执行期间用最新观察修正当前动作。论文报告动态仿真平均成功率由 GR00T 的 27.5% 提升至 85.0%，三个 Panda 实机任务的平均成功率由 51% 提升至 73%。它提供了无需每步重跑完整 VLA、仍可利用执行期视觉反馈的具体接口。

证据范围　CoRL 官方录用名单确认主会身份，所列日期为预印本首发日。方法依赖慢规划器先给出合理动作，单步局部去噪不足以挽救严重错误的计划。实机反馈推理为 1.95 ms，但完整传感与控制链路约 71 ms，不能把模型推理耗时当成端到端响应延迟；遮挡、观察噪声和接触附近的突变仍是限制。

机器人学习 / 数据选择 · 回顾

DataMIL: Selecting Data for Robot Imitation Learning with Datamodels

2025-05-14

得克萨斯大学奥斯汀分校 / MIT / 斯坦福大学 · ICLR 2026 主会论文 · 仿真与实机

方法与结果　DataMIL 估计先验训练数据对目标策略表现的影响，用目标示范上的验证损失替代昂贵 rollout，并选择高贡献数据与目标示范共同训练。正式版附录表 1 的实机平均成功率为 61.0%，对比 All-Data 的 30.9% 和 STRAP 的 39.8%；研究覆盖 60 多个仿真与实机任务，也展示了跨机器人形态选取 OXE 数据。

证据范围　ICLR 正式论文集确认主会身份，日期为 2025 年预印本首发日，结果按 2026 会议版核对。估计 datamodel 的成本仍是直接训练策略的数倍，选取比例与聚类等超参数也影响结果；目标任务规模有限，不能把数据筛选收益直接视为通用机器人自我改进，验证损失也只是成功率代理。

AI agents / 可验证研究流程

A thousand fewer paths to root

2026-11-04

OpenAI · 官方技术报告 · 隔离环境中的软件验证

方法与结果　报告将代码审查、动态复现、影响验证和候选补丁生成串成 agent 流程，再由人类研究员审查。一次运行从 2,308 个候选发现中动态复现 1,724 项漏洞，按对应补丁去重后得到 948 项本地提权漏洞证据，API 总成本约 121 万美元。值得借鉴的是逐阶段保存可运行证据，把发现数量与验证后的有效成果分开统计。

证据范围　这是特定 Linux 配置和未公开 cyber 模型上的研究结果，补丁仍需维护者审查；其中一些问题在扫描结束前已被社区修复或讨论，948 不能等同于独立新披露或已合并修复数量。报告成本为 API 费用，不能当成完整人力与计算成本，也未证明系统能自主改进自身的学习算法。
