语言指令遵循 · 组合泛化 · 回顾

Diagnosing Compositional Generalization in Sequential Robot Tasks

2026-10-15

UC Berkeley · CoRL 2026 主会论文 · 仿真

方法与结果　将序列操作的泛化差距分解为指令边际、指令组合及上下文—动作分布偏移，并用控制实验检查训练集应覆盖哪些依赖关系。稀疏对角任务预训练后，为每个完整任务补充 1 条示范，可将原预训练未见组合上的成功率从 0.4% 提升至 54.7%；结果支持部分失败来自技能的指令调度，而不只是缺少底层技能。

证据范围　实验主要是三个小型序列操作仿真任务族，策略在冻结视觉编码器上训练，尚未验证对大规模预训练 VLA 的迁移。补充示范已覆盖原预训练未见任务，因此 54.7% 不能解读为微调后仍完全零样本的泛化；跨阶段依赖的结论也受任务构造范围限制。

AI agents · 科研加速 · 自我改进证据

Research acceleration: The jagged frontier

2026-11-18

OpenAI · 官方研究报告

方法与结果　从内部 agent 使用、研究活动和产出三个层面测量 AI 研发加速。3 月至 10 月，预估需人类 2–4 小时的任务，其无人工干预成功率估计从 23% 升至 46%，4–8 小时任务从 13% 升至 35%；按工作类型拆分，监控训练为 79%，推理与服务代码编写为 25%，显示科研自动化存在明显能力落差。

证据范围　这是内部工作流的观察性测量，不是固定任务集合上的随机对照；研究人员随能力变化而改变委派任务，也会影响各时间桶的成功率。使用时长、代码量和实验数量都是代理指标，尚不能单独证明端到端科研产出按同比例增加，更不能直接视为无人参与的递归自我改进已经实现。

人机协作 · Agent 影响 · 实验设计

How AI agents shape experts’ judgment calls

2026-10-27

Anthropic Alignment · 官方研究博客 / 随机实验

方法与结果　让 50 名使用 Claude Code 的专业分析师完成同一个统计分析任务，并随机指定 agent 在每个可辩护选项之间的倾向。四类分析选择中，人类与 agent 倾向一致的比例合计为 86%；事后 77% 的分析师至少一次复述了 agent 的论据，而只有 15% 明确将其归因于 agent。研究提示，专家保留最后确认权，并不保证关键判断不受 agent 的偏好塑形。

证据范围　实验刻意强化 agent 的立场，只涵盖一个领域任务和一个模型，分析师也并非该应用领域的专家，真实工作中的影响强度可能不同。86% 衡量选项一致性，不代表错误率；不用 AI 的对照参与者是自行选择的，不能据其耗时和错误差异推断 AI 的因果生产率收益。
