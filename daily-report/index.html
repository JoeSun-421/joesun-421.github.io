ELASTIC: Efficiently Learning to Adaptively Scale Test-Time Compute for Generative Control Policies

2026-06-30

Carnegie Mellon University · CoRL 2026 主会论文 · 仿真与实机

方法与结果　将动作生成的算力分配建模为元 MDP：冻结基础策略，由强化学习训练的元策略按状态调整去噪步长、保留或剪除并行动作候选。在扩散策略仿真任务中优于固定分配与单轴扩展；在 π0.5 驱动的实机杯子入篮任务上，达到 best-of-10 的成功表现，同时将推理延迟降低 34%。

证据范围　34% 指单次推理的墙钟延迟，不是整项任务完成时间；实机每种方法使用 20 次试验。收益依赖学习到的验证器和额外交互，元策略目前按任务训练，尚未证明对未见任务或环境的迁移；这里调节的是动作生成算力，并非语言推理 token 长度。

Worse Together: How Performance Breaks Down in Multi-User Multi-Agent Teams

2026-11-11

Anthropic / Anthropic Fellows Program / independent collaborator · 官方研究博客 / 研究论文

方法与结果　构建共享 API 预算、诊所排期、团体订单与代码合并队列四个仿真环境，比较每用户一个 agent 与单个 agent 服务所有用户。两种 Claude 模型在四个环境中，单个协调者的归一化群体得分均高于点对点团队，差距约 10–45 个百分点；下单前强制读取待收消息，挽救了约 73% 和 62% 的失败团队订单试次。

证据范围　研究针对用户目标和偏好不同、且竞争共享资源的设置，不能外推为所有多 agent 系统都不如单 agent。结果来自仿真用户与特定工具环境，协调者与团队的信息组织也不同；得分差距和失败试次挽救比例均不是通用部署成功率。

Building strong safety evaluations

2026-11-13

Anthropic Engineering · 官方方法与评测经验博客

方法与结果　围绕设计、运行和报告评测，强调用多轮情景测试、人工校准评分器、匹配部署配置，并报告不确定性。一个实证例子是多轮评测中的 98% 与 94% 得分差异并不显著；同一模型的 API 与产品配置在部分评测上可相差最多 34 个百分点，说明配置差异和采样噪声足以改变结论。

证据范围　这是安全评测的方法经验总结，并非新的机器人算法或统一性能提升实验。文中数值来自不同内部评测与具体产品配置，不能跨设置直接比较；迁移到机器人实验时，仍需独立定义物理成功条件、人工干预口径与实际执行成本。
