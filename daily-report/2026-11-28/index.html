From spectrum to structure: Identifying molecules with Mass Spec Skills for Google Antigravity

2026-11-25

Google DeepMind · 官方研究博客 · 质谱工具使用评测

方法与结果　Mass Spec Skills 把谱库检索、分子式推断、候选结构评分和化学核查组织为可调用流程。在 100 个已收录于公开数据库的化合物上，每个谱图尝试三次；加入工具 Skills 后，轻量 Gemini 3.8 Flash 与两个前沿模型的精确识别率均约 97%。Flash 的每次生成 token 量约降至无网络、无 Skills 条件的四分之一，展示了可靠工具封装的作用。

证据范围　评测先过滤碎裂信息不足的谱图，且候选结构已在数据库中；约 97% 不是未知新分子的发现成功率。超出一小时预算计失败，但临时基础设施和配额错误被排除。部分异构体无法仅靠质谱区分，真正未入库分子仍需其他测量与专家判断；token 节省也不等于端到端实验时间同比缩短。
