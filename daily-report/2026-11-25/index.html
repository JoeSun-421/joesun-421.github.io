AI agents / 形式化验证

Finding faster quantum algorithms with agents and formal verification

2026-11-23

Google DeepMind / Google Quantum AI · 官方研究博客 · 算法搜索与形式化证明

方法与结果　多个 Gemini agent 团队独立搜索量子算法改进，候选经 Lean 验证后写入共享记录，并定期交流。聚变模拟案例的量子资源成本估算降低 11.8 倍，所需纠错量子比特由 5,650 降至 4,338；P450 模拟案例改善 2.5 倍。值得关注的是把正确性检查接入搜索循环，让共享经验受可检验约束。

证据范围　结果是特定算法的形式化正确性与资源估算，不是量子硬件上的墙钟加速；作者明确指出，应用仍可能超出早期纠错量子计算机的资源。研究方向和问题由人类设定，不能据此推断 agent 已能自主改进学习算法，或迁移到机器人闭环。

语言指令遵循 / 科学工具使用

GPT-6 models demonstrate intrinsic protein-design capabilities

2026-11-24

OpenAI / Onava · 官方研究博客 · 计算评测与湿实验

方法与结果　模型通过自然语言约束、推理和通用代码生成蛋白骨架，并可调整结合位置与结构形态。湿实验检测了基于 GPT-6.2 骨架设计的 322 个 minibinder，35 个显示结合信号，命中率 10.9%，覆盖五个靶点；这提供了模型输出经真实实验检验的证据，而不只是生成示例。

证据范围　骨架生成环节未调用专用生成模型，但该湿实验的序列建议和候选筛选仍使用专用蛋白模型，尚未证明零样本端到端设计完全独立于它们。结合信号也不等于功能、选择性或药效；完整结构预测仍明显落后于专用模型，部分公开基准存在记忆混杂。

Think Fast and Slow: Step-Level Cognitive Depth Adaptation for LLM Agents

2026-07-06

复旦大学 / 腾讯混元 · ICML 2026 主会论文 · 文本交互仿真

方法与结果　CogRouter 让 agent 每步选择四档认知深度，先用 CoSFT 建立各档行为，再以 CoPO 的置信度加权优势分配步骤信用。论文表 1 中，Qwen2.5-7B 在 ALFWorld 和 ScienceWorld 的成功率为 92.5% 与 72.0%；相比同一 CoSFT 初始化的 GRPO，两环境平均成功率提高约 14 个百分点，平均 token 用量由 4,367.3 降至 1,641.4，约减少 62%。
