MEM: Multi-Scale Embodied Memory for Vision Language Action Models

2026-03-08

Physical Intelligence / Stanford / UC Berkeley / MIT · CoRL 2026 主会论文 · 实机

方法与结果　将短期视频记忆与长期语言摘要结合：视频编码器压缩近期视觉变化，高层策略更新任务进度摘要并选择下一子任务。在备菜、清理厨房等需要最长约 15 分钟记忆的实机任务中，组合记忆优于无记忆及仅保留单一记忆的消融；还展示了利用过去失败调整抓取或开门策略。

证据范围　长任务实验每策略、任务或菜谱使用 10 次 rollout，并以分阶段任务进度等指标报告，不能把进度百分比读成完整任务成功率。纠错适应实验使用针对性的人类干预与纠正数据；结果不等于无需监督的在线学习，也未证明重置学习器后的递归自我改进。

Improving Fuzzy Robustness in LLM Safety with Automated Red Teaming

2026-11-12

OpenAI · 官方研究博客 / 技术论文

方法与结果　让自动攻击者增加测试时搜索预算，并用 worst@n 筛选多次复测仍稳定奏效的对抗样本，再用于防御模型的 RL 训练。受控实验中，用这些样本训练的模型，在未见攻击者生成的固定测试集和可继续调整策略的多轮攻击评测上，都比原始种子提示训练基线更鲁棒，显示收益不只局限于记住训练攻击。

证据范围　评测围绕特定安全边界、攻击者和评分器，不能推出对任意新攻击都安全。博客还报告不同代模型的部署前分数，但跨代差异同时包含模型与训练变化，不能全部归因于这一数据生成方法；文中模型层测试也不代表完整产品防护系统。

多模态推理 · 工具使用 · 实物验证

Testing Claude on real-world electronics design

2026-11-09

Anthropic / Diode Computers · 官方研究博客 · 电子硬件设计实验

方法与结果　测试 Claude Fable 5.2 从简短需求出发完成原理图、PCB 布局布线、外壳设计和固件，再由工程师制造验证。团队报告三款设备的原型均可工作、无须修改电路；内部 PCB Gym 得分由 Fable 5 的 25% 提升到 69%，BenchCAD 2.1 得分为 83.5%。它把复杂设计约束最终落到了可制造的实物上，值得作为 agent 长流程评测案例。

证据范围　三款原型属于小规模案例，制造和装配由人类完成，并非机器人自主生产。PCB Gym 为内部基准，分数不能直接解释为整机端到端设计成功率；原型长期可靠性与商业认证尚未验证。
